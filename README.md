# Zuumm Landing

The Zuumm Holidays landing page as a standalone static-front-end build —
extracted from the full product. All planner, wizard, chat and visa
surfaces are stripped; every CTA renders normally but is intentionally
inert (`href="#"` / no-op submits).

## Run

```bash
npm install
npm run dev    # http://localhost:3000
npm run build  # static production build
```

Built with Next.js 16, React 19, Tailwind v4 and Framer Motion.
Destination photography via Unsplash (free license).
